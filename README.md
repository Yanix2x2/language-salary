# Получение статистики вакансий на сайтах HeadHunter и SuperJob.

В коде записаны самые популярные языки разработки. Программа пробивает эти языки по доступным вакансиям на сайтах HeadHunter и SuperJob, выводит статистику по найденным вакансиям и вычисленную среднюю зарплату.

## Окружение

Рекомендуется использовать [virtualenv/venv](https://docs.python.org/3.13/library/venv.html) для изоляции проекта.

### Настройка виртуальное окружение
* Для Windows:
```bash
python -m venv env
venv\Scripts\activate
```

## Зависимости
Python3 должен быть уже установлен. Используйте `pip` или `pip3` для установки зависимостей:
```bash
pip install -r requirements.txt
```

## Переменные окружения

### Как получить

Для работы с HeadHunter ключ api не требуется.

Для работы с SuperJob нужно [зарегистрировать приложение](https://api.superjob.ru/info/). После регистрации, в параметрах доступа появится Secret key, который выглядит примерно так:
`v3.r.139001589.dcad0494270bf93e0ae4f92194327b999aa46ece.31cd09311d33dccede021243fc7bfe0000000000`

Ключ необходимо добавить в `.env`, предварительно создав его в корне проекта:
```
SUPERJOB_SECRET_KEY='your_secret_key'
```
## Запуск
Запуск программы производится через `main.py`
```bash
python main.py
```
